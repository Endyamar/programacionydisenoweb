Se pueden introducir los estilos de tres formas distintas:

  • Inline: introducir el estilo dentro del elemento.
  • Incrustado: incluir el estilo en la cabecera head de la página.
  • Enlazado: dentro de un archivo separado que se enlaza con el html.
