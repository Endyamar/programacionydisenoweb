Ejercicio Práctico: Uso de Imágenes sin CSS

Objetivo

Aprender a insertar imágenes en una página web utilizando únicamente HTML.

Instrucciones

Debes crear una página web que incluya:

  1. Un título principal.
  2. Una imagen local.
  3. Una imagen desde internet.
  4. Texto alternativo usando alt.
  5. Ancho y alto definidos.
  6. Una imagen que funcione como enlace.
  7. Uso de figure y figcaption.
  8. Uso de loading="lazy".
  9. No utilizar CSS.

Preguntas

  1. ¿Qué función cumple el atributo alt?

    2. El atributo alt sirve para proveer una descripción en caso de que no cargue la imagen y para dar servicio a los usuarios con problemas de visión

  2. ¿Qué ventaja tiene loading="lazy"?

    3. El lazy loading es una técnica de desarrollo web que permite cargar recursos solo cuando se necesitan. Este enfoque mejora la eficiencia y optimiza el rendimiento de los sitios web. A través del lazy loading, se minimiza el tiempo de carga inicial y se reducen los recursos consumidos. Esta práctica se ha vuelto esencial en la creación de experiencias de usuario más rápidas y fluidas.

  3. ¿Qué diferencia existe entre PNG y JPG?

    4. La principal diferencia es que JPG utiliza compresión con pérdida (menor tamaño, menor calidad, ideal para fotos) y PNG utiliza compresión sin pérdida (mayor tamaño, alta calidad, ideal para gráficos). Además, PNG admite fondos transparentes, mientras que JPG no.

  4. ¿Para qué sirve figcaption?

    5. El elemento HTML figcaption representa un subtítulo o leyenda asociado al contenido del elemento padre figure, pudiendo ser colocado como primer o último hijo. Es importante destacar que el elemento figcaption es opcional.
